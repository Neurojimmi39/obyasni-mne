# Объясни мне — AI-помощник для учёбы

Простой веб-прототип: ребёнок выбирает класс, предмет, тему и способ объяснения. Серверная функция `/api/explain` отправляет запрос в OpenAI API и возвращает объяснение + мини-тест.

## Переменные окружения

- `OPENAI_API_KEY` — секретный ключ OpenAI
- `OPENAI_MODEL` — модель, по умолчанию `gpt-5.6-luna`

Ключ нельзя помещать в `index.html` или переменную с префиксом `NEXT_PUBLIC_`.
